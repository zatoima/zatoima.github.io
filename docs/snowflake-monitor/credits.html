2026-09-02　Effective August 26, 2026 → September 1, 2026

96行追加・100行削除 数値を含む変更行 70

適用日が August 26, 2026 から September 1, 2026 に更新されました。新しいサーバーレス機能が追加され、AI_COMPLETE のモデル名・掲載順・注記が整理されています。単価そのものの変更は、提示された差分からは確認できません。

  • External Governance が追加され、単価は Snowflake-managed compute 1→1、Serverless compute 1→1 です。また、Serverless Experiments が追加され、単価は Snowflake-managed compute 0.9→0.9、Serverless compute 1→1 です。
  • AI_COMPLETE に claude-fable-5.15 が追加され、Input 6.00／Output 30.00 と設定されました。既存の claude-sonnet-520 は claude-sonnet-5 に名称変更され、単価は Input 1.20→1.20、Output 6.00→6.00 です。
  • claude-opus-4-75、claude-opus-4-85、claude-opus-55 が AI_COMPLETE の一覧内で再掲・配置変更されました。いずれも Input 3.00／Output 15.00 で、単価変更ではありません。
  • プロモーション注記が整理され、旧版にあった 50%値上げ（September 1, 2026） の記載が削除され、残る注記は 100%値上げ（January 1, 2027） となりました。その他、モデル名の空白、ハイフン、脚注番号、一覧順、見出しの改行などの体裁・文言修正もあります。

コストへの影響
新機能の利用時には、External Governance が 1、Serverless Experiments が 0.9 の Snowflake-managed compute 単価で課金対象になります。既存 AI_COMPLETE モデルの単価変更は差分上確認できず、将来のプロモーション価格については January 1, 2027 に100%値上げされる旨の注記が残っています。

2026-08-27　Effective August 18, 2026 → August 26, 2026

180行追加・154行削除 数値を含む変更行 111

Effective が August 18, 2026 から August 26, 2026 に変更されました。AI 関連の料金表構成が見直され、AI Sensitive Data Classification の項目と、Snowflake AI Features Table への参照が追加されています。AI_COMPLETE では新しいモデルが追加された一方、既存モデルの多くは同じ単価で再掲されています。

  • Sensitive Data Classification の行に、AI Sensitive Data Classification は「Table 6(g): Snowflake AI Features Table, Other」を参照する旨が追加され、AI Sensitive Data Classification の行自体も追加されました。
  • AI_COMPLETE – gemini-3.7-flash が追加され、単価は入力 0.45、出力 2.25（AI Credits per one million Tokens）です。行末に注記番号 21 が付いています。
  • AI_COMPLETE の既存モデル群（claude-sonnet、Gemini、Gemma、Grok、Llama、Mistral、OpenAI、Qwen など）は、旧単価を維持した状態で表内に再掲されています。確認できる範囲では、単価の変更はありません。
  • AI_COMPLETE – claude-opus-4-75 は、モデル名の空白位置だけが変更されています。単価は 3.00→3.00（入力）、15.00→15.00（出力）で、実質的な料金変更はありません。
  • AI_AGG、AI_CLASSIFY、AI_EMBED などの行は、提示された差分では削除されています。差分の続きが省略されているため、最終版で完全に削除されたのか、別位置へ移動したのかは判断できません。

コストへの影響
AI_COMPLETE の新モデル gemini-3.7-flash を利用する場合は、新たに入力 0.45／出力 2.25 クレジットの課金対象になります。既存モデルについては、提示範囲では単価変更が確認できず、AI Sensitive Data Classification は参照先変更のため、この差分だけではコスト影響を判定できません。

2026-08-20　Effective August 17, 2026 → August 18, 2026

102行追加・92行削除 数値を含む変更行 48

適用日が August 17, 2026 から August 18, 2026 に更新されました。主な変更は、Cortex AI のモデル追加・単価改定、Prompt Caching 料金表の追加、Snowflake CoCo の掲載整理です。AI_EMBED の一部モデルは価格を変えずに掲載位置のみ変更されています。

  • AI_COMPLETE では、openai-gpt-5.6-luna5 が 0.60→0.12、3.60→0.72 に値下げされ、openai-gpt-5.6-terra5 も 1.50→1.20、9.00→7.20 に変更されました。さらに、openai-gpt-5.6-luna-long-context5 と openai-gpt-5.6-terra-long-context5 が追加されています。
  • Prompt Caching の料金表（Table 6(b)）が追加され、openai-gpt-5.6-luna-long-context5、openai-gpt-5.6-sol5、openai-gpt-5.6-terra5、openai-gpt-5.6-terra-long-context5 について、Input、Output、Cache Write、Cache Read の単価が掲載されました。
  • Cortex Inference の料金では、openai-gpt-5.6-luna5 が 0.65→0.13、3.90→0.78、Cache Write なし→0.163、Cache Read 0.065→0.013 に変更されました。openai-gpt-5.6-terra5 も 1.625→1.30、9.75→7.80、Cache Write なし→1.625、Cache Read なし→0.13 となり、両モデルの long-context 版も追加されています。
  • AI_EMBED の snowflake-arctic-embed-m / -v1.5 は単価 0.03 のままで、プロモーション価格に関する注記の後ろへ掲載位置が移動しました。Legacy Cortex Features 付近にも空行が追加されており、これらは体裁・構成上の変更です。
  • Snowflake CoCo の表では、従来別位置にあった Claude 系モデルなどの行が Table 6(e) に整理・統合され、列見出しの間隔も調整されました。diff で確認できる掲載単価自体は、移動前後で変更されていません。

コストへの影響
openai-gpt-5.6-luna5 と openai-gpt-5.6-terra5 の一部利用コストは低下します。一方、long-context 版や Prompt Caching の Cache Write/Read 料金が新たに明示されたため、該当モデル・キャッシュ機能の利用時はトークン種別ごとの課金を考慮する必要があります。

2026-08-18　Effective August 10, 2026 → August 17, 2026

3行追加・2行削除 数値を含む変更行 2

2026年8月17日付けで Snowflake Service Consumption Table が改定された。主な変更は、AI関数 AI_SUMMARIZE5 の新規追加と、claude-sonnet-4-6 モデルの掲載テーブルの移動（Table 6(d) から Table 6(e) への再分類）の2点である。

  • AI関数テーブルに AI_SUMMARIZE5 が新規追加された。クレジット係数は 1.60。
  • claude-sonnet-4-6 が Table 6(d) から削除され、Table 6(e)（Snowflake CoCo）に移動された。単価自体は Input 1.65 / Output 8.25 / Cache Write 2.07 / Cache Read 0.17 で変更なし。
  • 適用日が August 10, 2026 から August 17, 2026 に更新された。

コストへの影響
claude-sonnet-4-6 の単価変更はなく分類移動のみのため、コストへの直接的な影響はない。AI_SUMMARIZE5 を新たに利用する場合はクレジット係数 1.60 が適用される。
