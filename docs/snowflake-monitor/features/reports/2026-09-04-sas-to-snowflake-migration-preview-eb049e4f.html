SAS ワークロードを Snowflake へ移行する AI 支援機能

SAS to Snowflake migration (Preview)

2026-09-04機能アップデートPreview

SAS 利用者は、SAS コードの評価・Snowflake SQL への変換・.sas7bdat のテーブル取り込みを AI で進められます。

Snowflake AIM Agent for Data Warehouses が、SAS ワークロードの Snowflake 移行を支援します。SAS コードベースの AI 支援アセスメント、SAS プログラムの Snowflake SQL への AI ベースのコード変換に対応します。また、SAS データセットファイル（.sas7bdat）を Snowflake テーブルへロードできます。本機能は Preview です。

01

なぜ重要か

従来は、SAS コードベースの調査、SQL への変換、SAS データセットの取り込みを個別に設計・実装する必要がありました。この機能により、SAS ワークロードの評価からコード変換、データ取り込みまでを Snowflake AIM Agent for Data Warehouses を使って支援できるようになります。

02

対象となるチーム

  • SAS 基盤・分析基盤の運用チーム
  • Snowflake 移行を担当するデータエンジニア
  • データウェアハウス移行プロジェクトのアーキテクト
  • SAS プログラムを保守する分析・開発チーム
03

提供条件

  • 提供ステータス: Preview
  • 対象機能: Snowflake AIM Agent for Data Warehouses
  • 対応ワークロード: SAS
  • エディション: リリースノートに記載なし
  • リージョン: リリースノートに記載なし
04

ユースケース

  • 既存の SAS コードベースを AI 支援でアセスメントし、移行対象や変換作業の初期把握に利用する。
  • SAS プログラムを Snowflake SQL へ AI ベースで変換し、移行候補となる SQL を作成する。
  • 既存の .sas7bdat ファイルを Snowflake テーブルへロードし、移行後のデータ基盤で利用する。
  • SAS から Snowflake への移行計画において、コード変換とデータ取り込みを含む初期検証を行う。
05

仕組みと使い方

Snowflake AIM Agent for Data Warehouses を使用して、SAS コードベースのアセスメント、SAS プログラムから Snowflake SQL へのコード変換、.sas7bdat ファイルの Snowflake テーブルへのロードを進めます。リリースノート本文には、具体的な SQL、コマンド、操作手順の記載はありません。詳細な操作方法は、関連ドキュメント「Snowflake AIM Agent for Data Warehouses - SAS Migration」を確認してください。

06

導入ステップ

  1. SAS Migration の関連ドキュメントを確認し、利用条件と操作方法を把握する。
  2. 対象となる SAS コードベースと .sas7bdat ファイルを移行検証用に整理する。
  3. Snowflake AIM Agent for Data Warehouses で SAS コードベースのアセスメントを実行する。
  4. SAS プログラムを Snowflake SQL に変換し、生成結果をレビューする。
  5. .sas7bdat ファイルを Snowflake テーブルへロードし、データ内容と処理結果を検証する。
07

運用上の注意

  • Preview 機能のため、本番移行の前に対象コードとデータを限定した検証を行う必要があります。
  • AI が変換した Snowflake SQL は、SAS と同等の結果になることを利用者が確認してください。
  • .sas7bdat から Snowflake テーブルへのロード結果について、スキーマやデータ内容を検証してください。
  • 必要な権限、利用条件、入力データの取り扱いは、関連ドキュメントで確認してください。
