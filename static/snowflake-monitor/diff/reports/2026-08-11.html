本日の総括

本日は Automatic Clustering の課金・動作モデル刷新 を筆頭に、Workday Live Data Query の統合ドキュメント群（新規5件）と AIM DMV の権限ページ新設が重なり、変更量・影響度ともに大きい日となった。領域としては「Loading & Unloading Data」と「Migrations」に新規ページが集中しており、ETL レス統合とデータ移行の強化という2つのトレンドが明確に読み取れる。2026年9月1日を境に Automatic Clustering の挙動が変わるため、既存ユーザーは直近でのコスト影響の再試算が急務である。

  • Automatic Clustering に Optima Clustering（取り込み量課金）と Clustering Classic（従来課金）の2モードが導入され、2026年9月1日以降に新規クラスタリングを設定したテーブルは自動的に Optima Clustering が強制適用される破壊的変更であり、既存テーブルへの移行手段は存在しない。
  • Workday Live Data Query for Snowflake の概要・セットアップ・クエリ手順・Cortex Code 活用・トラブルシューティングの5ページが一括追加され、ETL 不要でリアルタイムに Workday 人事データを Snowflake から直接照会できる統合機能が本格的にドキュメント化された（Snowflake 側は現在 Preview）。
  • AIM DMV（AI-powered Migration Data Migration Validation）の必要権限を Snowflake 側とソースプラットフォーム側に分けて解説するページが新設され、移行前にアカウント管理者と DBA 双方へ共有すべき GRANT 文が網羅されている。
