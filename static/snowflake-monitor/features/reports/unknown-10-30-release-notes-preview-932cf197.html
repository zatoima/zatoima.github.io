SNOWFLAKE NEW FEATURE / PRACTICAL BRIEF

時間範囲を単一値で扱う PERIOD data type が一般提供

10.30 Release Notes (Preview)

日付不明予定/進行中のサーバーリリースPreview

データ基盤や分析チームは、DATE・TIME・TIMESTAMPの半開区間を単一値として保存・比較・結合できるようになります。

PERIOD data type は、始点を含み終点を含まない [begin, end) の時間範囲を単一の値として保持します。要素型には DATE、TIME、TIMESTAMP を指定できます。PERIOD_CONSTRUCT や PERIOD_BEGIN、PERIOD_END など、範囲の構築・境界取得・比較・結合に使う関数が提供されます。本リリースノート自体は10.30のPreview段階で公開されており、PERIOD data typeの提供ステータスはGeneral availabilityです。

01

なぜ重要か

従来は時間範囲の始点と終点を個別の列や条件で管理する必要がありました。PERIOD data typeにより、アンカー付きの時間範囲を単一値として扱い、範囲の重複・包含・交差・差分などを専用関数で操作できます。

02

  • データウェアハウス設計者
  • SnowflakeのSQL標準化を担当するチーム

04

ユースケース

  • 有効期間や契約期間を、DATEまたはTIMESTAMPの範囲として単一値で管理する。
  • 複数の時間範囲について、重複や包含関係を判定する。
  • 時間範囲同士の交差部分を取得し、共通期間を分析する。
  • 隣接または重なり合う期間の差分を確認し、範囲の比較や統合に利用する。
05

仕組みと使い方

PERIOD値は、DATE、TIME、またはTIMESTAMPを要素型として構築します。本文で示されている主な関数は次のとおりです。

PERIOD_CONSTRUCT：PERIOD値を構築
PERIOD_BEGIN：開始境界を取得
PERIOD_END：終了境界を取得
PERIOD_OVERLAPS：範囲の重複を判定
PERIOD_CONTAINS：範囲の包含を判定
PERIOD_INTERSECT：範囲の交差を取得
PERIOD_LDIFF：範囲の左側差分を扱う
PERIOD_RDIFF：範囲の右側差分を扱う

具体的なSQL構文、戻り値、NULLの扱い、型変換規則はリリースノートに記載なしのため、公式のPERIOD data typeおよび各関数のリファレンスで確認してください。

07

運用上の注意

  • PERIODは半開区間 [begin, end) であり、開始境界は含みますが終了境界は含みません。日付や時刻の境界条件を既存ロジックと照合してください。
  • リリースノートはリリース完了前のPreviewであり、記載された機能がアカウントで利用可能になる時期はリリース完了状況に依存します。
  • PERIOD_CONSTRUCTなど各関数の詳細な挙動は本文だけでは判断できないため、導入前に公式リファレンスと実環境で確認してください。
