Automations in Snowflake CoWork (Public Preview)

2026-08-06機能アップデートPublic Preview

概要

Automations in Snowflake CoWork は、2026年8月6日にパブリックプレビューとして公開された機能です。この機能を使うと、一度きりのレポートを定期実行レポートに変換できます。設定したスケジュールに従い、Snowflake CoWork が最新データでクエリを再実行し、サマリーや主要メトリクスを含む結果をメールで送信します。メールにはフルレポートを開いてフォローアップの質問ができるリンクも含まれます。現時点ではパブリックプレビュー段階であり、一般提供（GA）ではありません。

ユースケース

  • 売上や在庫などのビジネスKPIを毎日・毎週自動でレポートとして受け取り、手動でダッシュボードを確認する手間を省く。
  • 週次の運用レポートをスケジュール設定し、担当者のメールボックスに定期配信することでモニタリング業務を自動化する。
  • 一度 CoWork で作成した分析レポートを定期実行に切り替えることで、最新データに基づいたインサイトを継続的に取得する。
  • チャット形式で CoWork に質問した際に、そのままスケジュール配信を設定し、定期的なフォローアップ分析を行う。

使い方

Automations は2つの方法で設定・管理できます。

1. チャット形式での設定
Snowflake CoWork に質問すると、CoWork が定期スケジュールでのレポート送信を提案することがあります。返信でタイミングを確認・調整することで自動化を設定できます。また、以下のような自然言語での操作が可能です。

- 「このレポートを毎週月曜日に送って」→ スケジュール設定
- 「自動化の一覧を見せて」→ 一覧表示
- 「このレポートの配信を一時停止して」→ 一時停止
- 「再開して」→ 再開
- 「削除して」→ 削除

2. Automations タブからの設定
Snowflake CoWork の「Automations」タブから、GUI 操作でスケジュールの設定・変更・管理が行えます。

※ SQL コマンドや API 経由での操作方法についてはリリースノートに記載なし。

手順

  1. Snowflake CoWork にアクセスし、分析したいデータについて質問する。
  2. CoWork が回答した際に、定期スケジュールでのレポート送信を提案するかどうかを確認する。
  3. 提案を受け入れるか、または自分でスケジュール（頻度・タイミング）を指定してオートメーションを設定する。
  4. 設定後は「Automations」タブで既存のオートメーションの一覧確認・編集・削除などの管理を行う。
  5. スケジュールになると、最新データで再実行されたレポートがメールで届くことを確認する。

注意すること

  • 本機能はパブリックプレビュー段階のため、仕様が変更される可能性があります。本番環境での重要なワークフローへの組み込みは慎重に検討してください。
  • レポート結果はメールで送信されるため、受信先のメールアドレスが正しく設定されているか事前に確認してください。
  • スケジュール実行時に使用されるデータは「実行時点での最新データ」であり、オートメーション設定時点のスナップショットではありません。データの更新タイミングに注意が必要です。
  • チャット経由でオートメーションを設定する場合、CoWork の提案タイミングや解釈に依存するため、意図した設定になっているか「Automations」タブで必ず確認してください。

制約事項

  • パブリックプレビュー段階の機能であり、SLA やサポートレベルはGAの機能とは異なる場合があります。
  • 対応エディションやリージョン制限についてはリリースノートに記載なし。
  • メール配信先の上限数や、設定可能なオートメーション数の上限についてはリリースノートに記載なし。
  • スケジュールとして設定可能な最小・最大間隔（例：毎分実行が可能かどうか）についてはリリースノートに記載なし。
  • SQL や外部 API からオートメーションを操作する方法についてはリリースノートに記載なし。
