SNOWFLAKE NEW FEATURE / PRACTICAL BRIEF

Organization Command Centerで組織横断テレメトリのPremium Viewsを管理

Organization Features in Organization Command Center (Preview)

2026-08-19機能アップデートPreview

GLOBALORGADMINがOrganization accountから、組織レベル機能とcross-account telemetry向けpremium viewsの有効状態を確認・管理できます。

Organization Featuresは、Organization Command Centerで組織レベルの機能の有効状態を確認するための画面です。Organization accountからOrganization Hub » Command center » Organization Features tileの順に開いて利用します。Preview段階では、主な管理対象はcross-account telemetry向けのpremium viewsです。premium viewsの有効化・無効化はSnowflake Supportを通じて行います。

01

なぜ重要か

従来は、組織レベルの機能が有効かどうかを確認するための専用画面が明確でない場合がありました。この機能により、GLOBALORGADMINがOrganization Command Centerから組織レベル機能の状態を確認できます。ただし、Preview段階であり、設定変更の実行主体はSnowflake Supportです。

02

対象となるチーム

  • Snowflake組織管理者
  • GLOBALORGADMINを管理するプラットフォーム運用チーム
  • 複数アカウントの監視・ガバナンスを担当するデータ基盤チーム
  • Snowflake Supportとの契約・問い合わせを担当する運用責任者
03

提供条件

  • 提供ステータスはPreviewです。
  • Organization accountが前提です。
  • アクセスできるのはGLOBALORGADMINロールです。
  • cross-account telemetry向けpremium viewsがPreview段階の主な管理対象です。
  • エディションおよびリージョンの要件はリリースノートに記載なし。
04

ユースケース

  • 組織横断のテレメトリを利用する前に、対象となるpremium viewsの有効状態を確認する。
  • 複数アカウントの監視やガバナンスを始める際に、組織レベル機能の有効化状況を棚卸しする。
  • premium viewsの有効化・無効化をSnowflake Supportへ依頼する前に、Organization Featuresで現状を確認する。
  • Preview機能の評価時に、GLOBALORGADMINが確認できる組織機能と、まだ委任できない管理範囲を整理する。
05

仕組みと使い方

Organization accountにGLOBALORGADMINロールでサインインし、Snowsightで次の順に開きます。

Organization Hub » Command center » Organization Features tile

表示された画面で、組織レベルの機能が有効かどうかを確認します。Preview段階での主な管理対象はcross-account telemetry向けpremium viewsです。premium viewsの有効化または無効化を希望する場合は、Snowflake Supportへ依頼します。SQLやSnowflakeコマンドによる設定例はリリースノートに記載なし。

06

導入ステップ

  1. Organization accountが利用可能であることを確認する。
  2. 確認担当者にGLOBALORGADMINロールが付与されていることを確認する。
  3. Organization accountへサインインし、Organization Hub » Command centerを開く。
  4. Organization Features tileを選択し、組織レベル機能とpremium viewsの状態を確認する。
  5. premium viewsの変更が必要な場合は、対象範囲と希望する状態を整理してSnowflake Supportへ依頼する。
07

運用上の注意

  • Preview機能のため、提供内容や動作が変更される可能性を考慮して評価する必要があります。
  • premium viewsの有効化・無効化は画面上で直接完了する方式ではなく、Snowflake Supportを通じて行います。
  • 設定変更を依頼する前に、組織横断テレメトリの利用目的と対象アカウントを整理してください。
  • Organization accountとGLOBALORGADMINの利用状況を、事前に組織管理者へ確認してください。
08

制約事項

  • Preview段階では、主な管理対象はcross-account telemetry向けpremium viewsです。
  • より細かな権限分離を行うapplication roleは、まだ利用できません。
  • Organization accountがない環境では、このCommand Centerページを利用できません。
  • GLOBALORGADMIN以外のロールによるアクセスは、リリースノートに記載なし。
  • エディション、リージョン別の提供条件、およびSQL・APIによる操作可否はリリースノートに記載なし。
09

次に確認すること

  • 公式のOrganization Command CenterおよびOrganization Featuresドキュメントで、最新の対象機能と操作条件を確認する。
  • Organization accountの有無と、実際に利用できるGLOBALORGADMINの担当者を確認する。
  • cross-account telemetryとpremium viewsを利用する業務要件、対象アカウント、必要な保持・参照範囲を整理する。
  • 有効化・無効化を検討する場合は、Snowflake SupportへPreviewの提供条件と変更手順を問い合わせる。
