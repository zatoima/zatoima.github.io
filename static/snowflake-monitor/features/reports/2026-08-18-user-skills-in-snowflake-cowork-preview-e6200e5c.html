Snowflake CoWorkで再利用可能なUser skillsを作成・実行

User skills in Snowflake CoWork (Preview)

2026-08-18機能アップデートPreview

Business usersが会話やUIから定型ワークフローをUser skillsとして作成し、必要な場面で明示的または自動的に実行できます。

User skillsは、Snowflake CoWorkで再利用可能なワークフローを定義する機能です。Business usersは会話形式、UI、またはskill folderのアップロードでスキルを作成できます。作成したスキルは、/やSkillsメニューから明示的に実行でき、会話内容に一致すると暗黙的に実行されます。2026年8月18日時点ではPreviewとして提供されています。

01

なぜ重要か

これまで会話のたびに同じ手順や指示を繰り返す必要がある業務では、手順の再利用が課題になり得ました。この機能により、定型ワークフローをスキルとして保存し、明示的または会話に応じて呼び出せるようになります。

02

対象となるチーム

  • 業務部門のBusiness users
  • データアナリスト・BIチーム
  • Snowflake管理者・Cortex Agent管理担当者
  • 定型業務の自動化を担当するチーム
03

提供条件

  • Public Preview
  • Snowflake CoWorkで提供
  • skillの作成や一部の実行にはCortex Agent code execution toolが必要
  • エディションの記載はなし
  • リージョンの記載はなし
04

ユースケース

  • 繰り返し行う分析手順やレポート作成手順をUser skillsとして保存し、必要なときに呼び出す。
  • Business users向けの定型的なデータ確認ワークフローを会話から再利用する。
  • 複数の手順をまとめたワークフローをskill folderとして登録し、Skillsメニューから実行する。
  • スクリプトを実行する処理やファイルを組み立てる処理を、対応するUser skillとして利用する。
05

仕組みと使い方

User skillsは次の方法で作成・実行します。

作成方法:
- Snowflake CoWorkの+メニューからSkills > Create newを選択する。
- 会話形式でスキルを作成する。
- Capabilities > Skillsからskill folderをアップロードする。

実行方法:
- /を使って明示的に実行する。
- Skillsメニューから選択して実行する。
- 会話内容がスキルに一致した場合、暗黙的に実行される。

会話またはCreate newによる作成、およびスクリプト実行・ファイル組み立てを行うスキルの実行には、Cortex Agent code execution toolが必要です。リリースノートにSQLやCLIコマンドの例は記載されていません。

06

導入ステップ

  1. 公式ドキュメントでUser skills in Snowflake CoWorkの前提条件と利用可能範囲を確認する。
  2. Cortex Agent code execution toolが必要な操作と、利用に必要な権限を確認する。
  3. Snowflake CoWorkの+ > Skills > Create newから小規模な定型ワークフローを作成する。
  4. 必要に応じてCapabilities > Skillsからskill folderをアップロードする。
  5. /またはSkillsメニューで明示的に実行し、会話に一致した場合の暗黙的な実行も検証する。
  6. スクリプト実行やファイル組み立てを含む場合は、Cortex Agent code execution toolの動作と権限を追加検証する。
07

運用上の注意

  • Preview機能のため、業務の標準手順として広範囲に展開する前に、対象業務を限定して検証してください。
  • 会話またはCreate newによるスキル作成にはCortex Agent code execution toolが必要です。
  • スクリプトを実行するスキルやファイルを組み立てるスキルにも、Cortex Agent code execution toolが必要です。
  • 暗黙的な実行を利用する場合は、意図しない会話でスキルが選択されないかを確認してください。
08

制約事項

  • Preview段階であるため、仕様や提供条件が今後変更される可能性があります。
  • Cortex Agent code execution toolが必要な操作では、同ツールを利用できない環境では実行できません。
  • エディション別の提供条件はリリースノートに記載なしです。
  • リージョン別の提供条件はリリースノートに記載なしです。
  • スキルの詳細な制限、権限モデル、共有範囲、監査方法はリリースノートに記載なしです。
09

次に確認すること

  • 公式ドキュメントのUser skills in Snowflake CoWorkで、作成形式、skill folderの構成、実行条件を確認する。
  • Cortex Agent code execution toolの公式ドキュメントで、必要な権限、実行環境、セキュリティ条件を確認する。
  • 検証用の限定的なUser skillを作成し、明示的実行と暗黙的実行の結果を比較する。
  • 対象アカウントでのPreview利用可否、エディション、リージョン、組織のPreview利用方針をSnowflake管理者に確認する。
